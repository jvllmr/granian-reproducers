# file upload redirect granian bug

## Description

FastAPI has the odd behavior that it creates temporary redirects if it expects a trailing `/`.
When uploading a file that is more than a few kilobytes big to an endpoint that redirects, granian closes the connection unexpectedly.
This does not happen with uvicorn or gunicorn.

Since I observed this bug not all the time under all conditions I'm not 100% sure that this reproducer always works.
In other scenarios I did not observe a closed connection, but a network request that is pending forever.

I managed to reproduces this consistently with the following environment:

- OS: Fedora 44
- Browser: Google Chrome (Version 151.0.7922.137 (Official Build) (x86_64))

## How to use this reproducer

1. Clone this repo
2. Make sure uv is installed
3. Start webserver in root of this repo via `./start.sh file_upload_redirect`
4. Open `http://127.0.0.1:8000`
5. Choose 250 kB file or `test.txt` generated by the server in this directory
6. Submit form and observe bug
